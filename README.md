# Lecture Schedule Spreadsheet and LaTeX Template

This repository contains: two files:

1. the Excel/LibreOffice file `lecture_schedule_to_LaTeX.xlsx`
2. the LaTeX source file `syllabus_template.tex`

## The Excel/LibreOffice file

The spreadsheet is for planning a semester-long course schedule. The main output is the corresponding LaTeX table code. No macros are used.
Alternatively, one can use the following equivalent [Google Sheets document](https://docs.google.com/spreadsheets/d/1gfeErVIzK9o9KlgYscAHgbvGePsBxHcZ5Q-O7JI43ok/copy).
That link in full: 

`https://docs.google.com/spreadsheets/d/1gfeErVIzK9o9KlgYscAHgbvGePsBxHcZ5Q-O7JI43ok/copy`

Make sure you make a copy to Sheets associated with your Google account. 

Note that unlike with the .xlsx document, Google Sheets encloses the LaTeX table output in double quotes ("). Make sure you remove them after pasting into your .tex document.

The spreadsheet is intended to remove most of the repetitive work involved in constructing a lecture schedule. 
After the first class date, regular meeting days, chapter numbers, topics, holidays, and examinations have been entered, the workbook calculates the meeting dates and produces ready-to-paste LaTeX.

## The LaTeX source file
   
The .tex document produces the actual syllabus/ The final table of the syllabus, which is the class schedule, was copied and pasted from the spreadsheet.

## What the spreadsheet does

The workbook:

* generates possible meeting dates from the first class date and the selected meeting weekdays;
* groups meetings by instructional week;
* handles weeks with different numbers of meetings;
* handles month changes within a week;
* supports ordinary class meetings, holidays, examinations, and other special entries;
* produces `\multirow` entries for week and month labels;
* inserts horizontal rules between weeks;
* can generate output for either a `tabular` or a `longtable` environment;
* uses nonbreaking row endings in `longtable` mode so that a week is not split unnecessarily across pages;
* counts scheduled meetings and numbered lecture meetings;
* includes a `Tests` sheet with checks for representative output features.

## Spreadsheet workflow

Most users need to work only in the `Schedule` sheet and, when necessary, the `Settings` sheet.

1. Enter the first day of class.
2. Mark the weekdays on which the class normally meets.
3. Enter chapter numbers or other labels in the `Chapt.` column.
4. Enter lecture topics, holidays, examination descriptions, or other events in the `Title` column.
5. In `Settings`, choose either `tabular` or `longtable`.
6. Copy the generated LaTeX from cell `Schedule!B13`.
7. Paste it into the marked location in the LaTeX source.

The final active meeting is determined by the last row containing an entry in either the `Chapt.` or `Title` column. Rows below that point are ignored.

Cells intended for user input are distinguished by their background color. Formula cells and support sheets are protected to reduce accidental changes; this protection is organizational rather than a security feature.

## Workbook structure

* **Schedule** — user input, generated dates, summary information, and final LaTeX output.
* **Settings** — configurable LaTeX fragments, output mode, and planning summaries.
* **Dates** — generates the sequence of possible class dates.
* **Calculations** — determines active rows, week and month spans, and LaTeX fragments.
* **Tests** — checks selected formulas and output conventions.
* **Export** — assembles the final LaTeX rows.

## LibreOffice Calc and Microsoft Excel

The `.xlsx` workbook was developed and tested primarily in **LibreOffice Calc**. It uses ordinary spreadsheet formulas, conditional formatting, and sheet protection, and does not require macros.

It should also work in recent versions of **Microsoft Excel**, although small differences in formatting, text-box layout, protection behavior, or formula display may occur.

## LaTeX usage

The supplied LaTeX file demonstrates the `longtable` form of the generated schedule. The spreadsheet can also generate rows for an ordinary `tabular` environment.

For the schedule table itself, the relevant packages are:

\usepackage{longtable}
\usepackage[longtable]{multirow}

With `longtable`, more than one compilation of the .tex document may be needed for widths and page breaks to settle.
